### The entire main storyline is plotted and has entered the coding phase! New missions will be uploaded directly here as they are completed.

![Downloads](https://img.shields.io/github/downloads/chemtrailoperator/Endgame-Alpha_EndlessSky/total)


Note: This plugin is still very much a work in progress, so I wouldn't necessarily recommend it yet if you are looking for just gameplay. If you are familiar with game saves (and how to revert changes), go ahead. If you don't want things messed up, star the repo and come back in a month or two.

Feel free to contribute or point out errors and bugs in the issues section of this repo. A bunch of major additions and changes are coming, the entire story is plotted out, and v1.0 will be released soon.

This plugin requires at least Endless Sky v0.10.16, it should be stable through 11.2

This plugin allows you to serve in the Navy and earn the Navy licenses that are currently in-game and unobtainable, and it will also add general content and other things we thought would be nice in the game. There are over 135 missions and a bunch of supporting mechanics, ships, and outfits.

Make sure you create a game save at the start of the story, the storyline is currently incomplete and many worlds will become inaccessible/hostile permanently. Due to testing needs, there is a Navy shipyard on Rutilicus that has a bunch of ships. If you don't have a Navy license, this shouldn't affect gameplay, but it isn't lore accurate.
