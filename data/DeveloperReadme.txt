
#This is a short description of the mission naming protocol used in Takeover and onwards, as well as mechanics. Some features may not reflect this, since a complete version 1 beta is the priority. We will back issue compliance as we can.
# Storyline missions receive a blank serial number sequentially following the main part of the storyline, the subheading, and the mission itself. Missions are subdivided as many times to accomodate all of the necessary missions while going into double digits as little as possible to reduce confusion when deleting stuff from save files.
# Epilogue missions carry standard serialization, with the prefix P
# Mechanics missions that power the backend such as npc fleets have the prefix M
# Patches for previous versions carry the prefix X
# The P prefix comes before M or x
# Jobs will eventually be serialized with prefix J
